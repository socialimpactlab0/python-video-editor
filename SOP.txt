# Python Video Editor 使用說明書

## 第一步：下載程式

到 GitHub 下載整個專案：

```
https://github.com/socialimpactlab0/python-video-editor
```

點 **Code → Download ZIP** → 解壓縮到你想要的資料夾

---

## 第二步：安裝

1. 確認已安裝 **Python 3.8+**（安裝時勾選 `Add Python to PATH`）
2. 在專案資料夾內，**雙擊** `install.bat`
3. 等待自動安裝完成（Python 套件 + FFmpeg）

---

## 第三步：啟動程式

雙擊 `run.bat`，會出現選單：

```
================================================
  Python Video Editor
================================================

  [1] 剪切影片（設定開始/結束時間）
  [2] 合併多個影片
  [3] 縮放影片尺寸
  [4] 加上文字字幕
  [5] 提取音訊
  [6] 替換 / 混合音訊
  [7] 調整播放速度
  [8] 轉換影片格式
  [9] 查看影片資訊
  [0] 離開

請選擇功能 (0-9):
```

---

## 各功能說明

### [1] 剪切影片
把影片剪成你要的片段。

| 輸入項目 | 說明 | 範例 |
|---|---|---|
| 輸入影片路徑 | 可以直接把檔案拖曳進視窗 | `C:\Videos\my_video.mp4` |
| 輸出檔案名稱 | 剪完後存成什麼名字 | `output.mp4` |
| 開始時間（秒） | 從第幾秒開始 | `10`（第10秒） |
| 結束時間（秒） | 剪到第幾秒，直接按 Enter = 剪到結尾 | `30`（第30秒） |

---

### [2] 合併多個影片
把多個影片首尾相接合成一個。

| 輸入項目 | 說明 | 範例 |
|---|---|---|
| 輸出檔案名稱 | 合併後的檔案名 | `merged.mp4` |
| 影片路徑 | 用**空格**分隔多個檔案 | `clip1.mp4 clip2.mp4 clip3.mp4` |

---

### [3] 縮放影片尺寸

**方式一：按比例縮放**

| 輸入 | 說明 |
|---|---|
| `0.5` | 縮小到原本的 50% |
| `2.0` | 放大到原本的 200% |

**方式二：指定寬高像素**

| 常用尺寸 | 寬 × 高 |
|---|---|
| 1080p | 1920 × 1080 |
| 720p | 1280 × 720 |
| 480p | 854 × 480 |

---

### [4] 加上文字字幕
在影片上疊加文字。

| 輸入項目 | 說明 | 範例 |
|---|---|---|
| 文字內容 | 要顯示的文字 | `歡迎觀看` |
| 出現時間 | 第幾秒出現 | `2` |
| 消失時間 | 第幾秒消失，Enter = 到結尾 | `8` |
| 位置 | 文字在哪裡 | `bottom`（下方） |
| 字體大小 | Enter = 預設 48 | `60` |
| 文字顏色 | Enter = 預設白色 | `white` / `yellow` / `red` |

**位置選項：**
```
top-left    top    top-right
left       center      right
bottom-left  bottom  bottom-right
```

---

### [5] 提取音訊
把影片裡的聲音存成音訊檔。

| 輸入項目 | 說明 |
|---|---|
| 輸入影片 | 來源影片 |
| 輸出音訊 | 存成 `.mp3` / `.wav` / `.aac` |

---

### [6] 替換 / 混合音訊

- **替換**：把原本的聲音換掉，換成新的音訊
- **混合**：保留原聲，再疊加新音樂（選 `y`）

---

### [7] 調整播放速度

| 倍率 | 效果 |
|---|---|
| `0.5` | 慢動作（半速） |
| `1.0` | 原速（不變） |
| `2.0` | 兩倍速 |
| `4.0` | 四倍速 |

---

### [8] 轉換影片格式
輸出時的**副檔名**就決定格式：

| 副檔名 | 格式 |
|---|---|
| `.mp4` | MP4（最通用） |
| `.avi` | AVI |
| `.mov` | QuickTime |
| `.mkv` | MKV |
| `.webm` | WebM |

---

### [9] 查看影片資訊
顯示影片的基本資料：

```
File     : my_video.mp4
Duration : 00:01:30.000（90秒）
FPS      : 30
Size     : 1920 × 1080 px
Audio    : yes
File size: 45.2 MB
```

---

## 小技巧

- 輸入影片路徑時，可以**直接把檔案拖曳**進黑色視窗，自動填入路徑
- 每個功能完成後按任意鍵就會回到主選單
- 支援的影片格式：`.mp4` `.avi` `.mov` `.mkv` `.webm` `.flv` `.wmv`
- 支援的音訊格式：`.mp3` `.wav` `.aac` `.ogg` `.flac`
